Product Design Case Studies

User research, competitive analysis, and engagement design — from real-time interviews to validated prototypes.

Rainforest Connection (T4SG)

Research

  • Conducted competitive analysis of conservation app landscape
  • Ran live user interviews to identify core pain points
  • Synthesized insights into design priorities

Design & Validation

  • Designed interaction flows balancing usability with mission impact
  • Iterated based on real-time user feedback
  • Translated research insights → coherent design system

Key Outcomes

  • Research discipline: Live interviews, not assumptions
  • Systems thinking: Balancing competing user + mission needs
  • Startup mindset: Rapid iteration on user feedback

Skills Demonstrated

User Research Competitive Analysis Interaction Design Real-time Iteration Emotional Design Systems Thinking

Key Insight & Next Steps

What I learned: User interviews revealed a critical gap between wanting to help and understanding impact. Users needed real-time feedback to feel their actions mattered.

Room for improvement: Would A/B test two engagement loop designs (immediate feedback vs. weekly digest) to measure which drives sustained usage. Metrics: 7-day retention, feature adoption, time-in-app.

JPMorgan (Product Lab)

Research

  • Led market research + competitive analysis for financial workflows
  • Conducted real-time user interviews with target personas
  • Identified core friction: decision paralysis in high-stakes scenarios

Design & Validation

  • Designed system reducing cognitive load through progressive disclosure
  • Balanced information density with confidence-building interactions
  • Prototyped flows, validated with users in real-time

Key Outcomes

  • User research focus: Real interviews → behavioral insights
  • Complex domain UX: Translated finance into scannable, actionable UI
  • Startup skill: Fast iteration from research → prototype → validation

Skills Demonstrated

User Research Competitive Analysis Behavioral Design Progressive Disclosure Complex Domain UX Real-time Iteration

Key Insight & Next Steps

What I learned: Decision paralysis wasn't caused by lack of information — it was information overload. Users needed confidence signals (like trust anchors and progressive commitment) more than more data.

Room for improvement: Would validate prototype with eye-tracking studies to identify exactly where users struggle. Then A/B test engagement patterns (similar to Candle's micro-interaction thinking) to build confidence at key decision points.

Approach

Both projects follow the same workflow: user research → identify friction → design systems → validate with real users → iterate. For a role like Candle focused on engagement and retention, this translates to understanding behavior, designing for emotional impact, and measuring what actually works.
