Synthetic → Real Object Detection

Unity Perception + SynthDet · YOLOv8 · Weights & Biases · Domain Shift Analysis

Overview

I built and evaluated an end-to-end object detection pipeline that begins with synthetic labeled images generated in Unity (Perception + SynthDet), then tests transfer to real photos and finetunes to reduce synthetic-to-real domain mismatch.

The focus was not only model performance, but structured evaluation, clear error analysis, and transparent iteration decisions.

Key Takeaway: Synthetic-only training appeared reasonable on synthetic validation data, but produced zero correct detections on real photos. This exposed domain shift clearly and guided the decision to incorporate real-image finetuning.

Problem Framing

Synthetic data enables rapid prototyping, but real-world deployment depends on generalization. Rather than assuming transfer would work, I explicitly tested the boundary between synthetic and real domains.

The core question became:

Does synthetic-only training meaningfully transfer to real-world images?

Pipeline

1. Synthetic Dataset Generation

  • Built Unity scene with RGB capture using Unity Perception
  • Exported labeled data via SynthDet
  • Converted annotations to YOLO format
  • Split train/validation (8:2)

2. Training + Analysis

  • Trained YOLOv8 on synthetic dataset
  • Logged metrics and artifacts to Weights & Biases
  • Used confusion matrices and detection previews to diagnose errors

3. Transfer Evaluation

  • Evaluated synthetic-trained model on real photos
  • Observed complete failure across all classes
  • Identified lighting, background, and texture mismatch as likely causes

Results

Synthetic Validation

  • mAP@0.5: 0.248
  • mAP@0.5–0.95: 0.191
  • Precision: 0.287
  • Recall: 0.248

Model learned meaningful signal within synthetic domain.

Real-World Evaluation

Before finetuning, the model produced zero correct detections on real photos.

This clarified that the issue was domain calibration, not model architecture.

Finetuning with Real Images

Real Dataset

  • Collected and labeled small real-image dataset
  • Converted to YOLO format
  • Used full-image bounding boxes (one class per image)
  • Split train/validation (8:2)

Finetuned Model (Real Validation)

  • mAP@0.5: ~0.252
  • mAP@0.5–0.95: ~0.249
  • Precision: ~0.289
  • Recall: ~0.264

Performance improved directionally but was constrained by dataset size and coarse labeling.

Implementation Snapshot

  • Parsed SynthDet JSON labels and normalized bounding boxes to YOLO format (xc, yc, w, h ∈ [0,1])
  • Programmatically generated dataset.yaml with class-index mapping
  • Trained YOLOv8 with Weights & Biases logging for reproducible experiment tracking
  • Resumed training from synthetic checkpoint for real-image finetuning

What I Learned

  • Domain shift is measurable: synthetic-only training did not generalize without calibration.
  • Error analysis accelerates iteration: confusion matrices and detection previews surfaced failure modes quickly.
  • Data quality dominates architecture tweaks: limited real samples and coarse labels constrained performance.
  • Clear communication matters: framing the failure as miscalibration (not model failure) aligned next steps logically.

Next Steps

  • Increase real-image diversity (lighting, backgrounds, textures)
  • Replace full-image boxes with object-level bounding boxes
  • Rebalance classes and target low-recall categories
  • Continue structured experiment tracking for transparent iteration
