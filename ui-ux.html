UI/UX Case Studies

Interaction design and emotional design — from user research to validated prototypes.

Rainforest Connection (T4SG)

Research

  • Conducted competitive analysis of conservation app landscape
  • Ran live user interviews to identify core UX pain points
  • Synthesized insights into interaction priorities

Design & Validation

  • Designed interaction flows balancing usability with mission engagement
  • Prototyped in Figma; iterated based on real-time user feedback
  • Built cohesive design system across user journeys

Key Outcomes

  • Interaction design: Flows that drive engagement + clarity
  • Emotional design: Making impact visible to users
  • User-centered: Decisions grounded in real feedback, not assumptions

Skills Demonstrated

Interaction Design User Research Competitive Analysis Prototyping (Figma) Emotional Design Real-time Iteration

Key Insight & Next Steps

What I learned: User interviews revealed that seeing real-time impact was critical to sustained engagement. Users needed visual feedback loops showing their actions matter.

Room for improvement: Would A/B test two interaction patterns (immediate micro-feedback vs. delayed summary) to measure which drives sustained engagement. Metrics: 7-day return rate, feature adoption, time-in-app.
